# elixir_simple_oauth - 模块设计

## 1. 核心模块
- 聚合入口：`SimpleOAuth`。
- Provider 模块：`SimpleOAuth.Google/Wechat/QQ/SGM/Lark`。
- HTTP 客户端：`*/client.ex`。
- Token 缓存：`SimpleOAuth.TokenServer` + `Record/Context`。

## 2. 启动结构
`SimpleOAuth.Application`：
- `SimpleOAuth.TokenServer`
- `{HLClock, name: SimpleOAuth.HLClock}`

## 3. 设计特征
- 通过 provider adapter map 做统一分发。
- 支持分布式场景下 token 更新时间协调（配置项 `distributed`）。
