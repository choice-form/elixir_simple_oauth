# elixir_simple_oauth - 关键流程

## 流程 1：获取用户信息
1. 应用调用 `SimpleOAuth.get_user_info(provider, code)`。
2. 分发到对应 provider 模块。
3. provider 先换 token，再拉取用户信息。
4. 返回标准化结果。

失败路径：
- token 获取失败：返回 `get_*_token_error`。
- user info 拉取失败：返回 `get_*_user_info_error`。

## 流程 2：token 缓存与刷新
1. provider 调用 `TokenServer.get(provider, key, fetcher)`。
2. 若缓存有效直接返回；否则触发 fetcher 更新。
3. 写回记录并返回 token。
